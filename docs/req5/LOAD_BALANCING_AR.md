# موازنة الحمل

يستخدم النظام round-robin عبر Docker DNS: nginx يعيد حل الاسم `app` ولا يحتفظ بعنوان حاوية واحدة. عند أخطاء الاتصال أو 502/503/504 ينتقل إلى نسخة أخرى.

لا نستخدم `ip_hash`. تثبيت العميل على نسخة واحدة يخفي أخطاء الحالة المحلية، وتضيع بياناته عند توقف النسخة. الحالة الصحيحة موجودة في MySQL وRedis وRabbitMQ ووحدة التخزين المشتركة.

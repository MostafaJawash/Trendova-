# تدقيق الحالة المحلية

| المشكلة | السبب | الإصلاح | الحالة |
| --- | --- | --- | --- |
| منافسة ناشر outbox | كل نسخة API كانت تشغّل حلقة نشر | قفل MySQL advisory واحد للناشر | يحتاج تحقق حي |
| تحديد محاولات الدخول | قاموس Python محلي لكل نسخة | عداد Redis مشترك مع TTL | يحتاج تحقق حي |
| ملفات الصور | يجب ألا تكون في قرص حاوية | volume `uploads` مشترك لكل النسخ | التهيئة موجودة؛ يحتاج تحقق حي |
| migrations وseed | بدء النسخ المتزامن قد يتسابق | قفل MySQL advisory عند البدء | يحتاج تحقق حي |

قبل/بعد: لا توجد نتائج مخترعة. شغّل أوامر `STATE.md` ثم احفظ الناتج في `docs/req5/results/`.
